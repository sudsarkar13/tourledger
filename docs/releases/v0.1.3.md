A Metro category, and redesigned drop-down menus.

## New

- **Metro** is its own category, counted under Travelling expenses on a claim. Typing
  `metro home to station 40` into Quick entry picks it; `auto to metro station` stays
  Local transport. A budget you set for Local transport no longer includes metro
  fares.
- **Drop-down menus** are redrawn as glass menus with icons: beside the field on a
  computer, rising from the bottom on a phone.

## Update your other devices too

**Update every linked device.** Versions before 0.1.3 do not know the Metro
category, and notes mentioning the metro are now filed under it by themselves. Once
you have such an entry, syncing with a device that has not updated stops with the
message "Pick a category." Nothing is lost, and syncing resumes after it updates.
From 0.1.3 on, a new category no longer does this.

## Updating

If you have 0.1.2, the app offers this update by itself (**More → Updates** to check
now). From 0.1.1 or earlier, install it by hand once. Your entries stay.

## Which file

| System | File |
|---|---|
| macOS 11 or later (Apple silicon and Intel) | `…_universal.dmg` |
| Windows, most PCs | `…_x64-setup.exe` or `…_x64_en-US.msi` |
| Windows on ARM | `…_arm64-setup.exe` |
| Debian, Ubuntu | `…_amd64.deb` or `…_arm64.deb` |
| Fedora, openSUSE | `…x86_64.rpm` or `…aarch64.rpm` |
| Other Linux (64-bit PC) | `…_amd64.AppImage` |
| Android 8 or later (ARM phones and tablets) | `…_android.apk` |

`latest.json` and `…app.tar.gz` are what installed apps use to update; you do not
need them.

## Security warnings you will see

The desktop apps are not signed with a paid developer certificate.

- **macOS:** open the app once, then go to System Settings → Privacy & Security and
  choose **Open Anyway**.
- **Windows, SmartScreen warning:** choose **More info → Run anyway**.
- **Windows, Smart App Control:** where it is switched on, Windows blocks the
  installer, including during an update.
- **Android:** allow your browser, file manager or TourLedger to install apps.
