TourLedger now updates itself. Your entries stay on the device when it does.

## Install this one by hand, once

Versions 0.1.0 and 0.1.1 cannot update themselves. Install 0.1.2 over the version
you have; nothing needs to be uninstalled and your entries stay. Save a backup first
(More → Backup and import). From then on, updates arrive in the app.

## How updating works

TourLedger asks GitHub for a newer release when it opens, and daily while it stays
open. It downloads one and asks before installing. Switch this off, or check yourself, under **More → Updates**.

- **macOS, Linux AppImage:** installs and restarts.
- **Windows:** the app closes, the installer runs, the app opens again.
- **Linux deb or rpm:** asks for your password.
- **Android:** the first time, allow TourLedger to install apps. Android may also
  ask you to confirm; newer versions often do not. The app closes when it is
  replaced; open it again. On mobile data it waits for you to press Download.

Nothing from your ledger is sent. GitHub sees your internet address, as any website
does.

## Which file

| System | File |
|---|---|
| macOS 11 or later (Apple silicon and Intel) | `…_universal.dmg` |
| Windows, most PCs | `…_x64-setup.exe` or `…_x64_en-US.msi` |
| Windows on ARM | `…_arm64-setup.exe` |
| Debian, Ubuntu | `…_amd64.deb` or `…_arm64.deb` |
| Fedora, openSUSE | `…x86_64.rpm` or `…aarch64.rpm` |
| Other Linux (64-bit PC) | `…_amd64.AppImage` |
| Android 8 or later (ARM phones and tablets) | `…_android.apk` |

`latest.json` and `…app.tar.gz` are what installed apps use to update; you do not
need them. iPhone and iPad are not included, and FreeBSD can only be built from
source.

## Security warnings you will see

The desktop apps are not signed with a paid developer certificate.

- **macOS:** open the app once, then go to System Settings → Privacy & Security and
  choose **Open Anyway**.
- **Windows, SmartScreen warning:** choose **More info → Run anyway**.
- **Windows, Smart App Control:** where it is switched on, Windows blocks the
  installer, including during an update, and offers no way to allow just this app.
- **Android:** allow your browser or file manager to install apps when asked.

## What has been tested

- Updating on macOS (Apple silicon) and on an Android emulator, with test builds.
- Updating on Windows, Linux and Intel Macs has **not** been tried.
