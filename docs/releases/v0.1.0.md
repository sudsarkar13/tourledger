The first version of TourLedger: tour and event expenses, claim reports, loans,
and sync between your own devices. No account.

**This is an early test release.** Save a backup (More → Backup and import) before
you rely on it.

## Which file

| System | File |
|---|---|
| macOS 11 or later (Apple silicon and Intel) | `…_universal.dmg` |
| Windows, most PCs | `…_x64-setup.exe` or `…_x64_en-US.msi` |
| Windows on ARM | `…_arm64-setup.exe` |
| Debian, Ubuntu | `…_amd64.deb` or `…_arm64.deb` |
| Fedora, openSUSE | `…x86_64.rpm` or `…aarch64.rpm` |
| Other Linux (64-bit PC) | `…_amd64.AppImage` |
| Android 8 or later (ARM phones and tablets) | `…_android.apk` |

iPhone and iPad are not included. FreeBSD can only be built from source.

## Security warnings you will see

The desktop apps are not signed with a paid developer certificate.

- **macOS:** open the app once, then go to System Settings → Privacy & Security and
  choose **Open Anyway**.
- **Windows:** on the SmartScreen warning, choose **More info → Run anyway**.
- **Android:** allow your browser or file manager to install apps when asked.

## If you used an earlier Android test build

This APK is signed with a different key, so it cannot install over it. In the old
app, save a backup somewhere outside the app (for example Downloads), uninstall it,
install this one, import the backup, then link your devices again.

## What has been tested

- macOS on Apple silicon: a local build of this code was installed and used. The
  download here is built separately and has not been run.
- Android: tried on an emulator.
- Windows, Linux and Intel Macs: **built automatically, never run.**
- Sync between two real devices has not been tested end to end.

Please report what breaks in the repository's Issues.
