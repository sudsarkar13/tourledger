Return journeys in one step, and reminders for your loan instalments.

## New

- **Return journey.** On a transport entry, switch on **Add the return journey** to
  save a second entry with From and To the other way round, with its own fare and
  date.
- **Loan reminders.** **More → Notifications**: be told before an EMI is due, on the
  day, and once if it is not marked paid. It is off until you switch it on, and
  amounts stay hidden unless you ask for them.
  - On Android reminders arrive with the app closed, sometimes late, more so on
    battery saver. Open the app after changes made on another device have synced.
  - On a computer they arrive while TourLedger is open.

## Updating

If you have 0.1.2 or later, the app offers this update by itself (**More → Updates**
to check now). From 0.1.1 or earlier, install it by hand once. Your entries stay.

## Which file

| System | File |
|---|---|
| macOS 11 or later (Apple silicon and Intel) | `…_universal.dmg` |
| Windows, most PCs | `…_x64-setup.exe` or `…_x64_en-US.msi` |
| Windows on ARM | `…_arm64-setup.exe` |
| Debian, Ubuntu | `…_amd64.deb` or `…_arm64.deb` |
| Fedora, openSUSE | `…x86_64.rpm` or `…aarch64.rpm` |
| Other Linux (64-bit PC) | `…_amd64.AppImage` |
| Android 8 or later (ARM phones and tablets) | `…_android.apk` |

`latest.json` and `…app.tar.gz` are what installed apps use to update; you do not
need them.

## Security warnings you will see

The desktop apps are not signed with a paid developer certificate.

- **macOS:** open the app once, then go to System Settings → Privacy & Security and
  choose **Open Anyway**.
- **Windows, SmartScreen warning:** choose **More info → Run anyway**.
- **Windows, Smart App Control:** where it is switched on, Windows blocks the
  installer, including during an update.
- **Android:** allow your browser, file manager or TourLedger to install apps.

## What has been tested

- Return journeys in a browser against the same code the app runs.
- Reminders on an Android emulator: switched off and on, an instalment marked paid,
  a restart, a reinstall, and one arriving with the app closed. Not tried on a real
  phone, where battery saving can delay them.
- Reminders on macOS, Windows and Linux have not been tried.
- Windows, Linux and Intel Macs: built automatically, never tried.
