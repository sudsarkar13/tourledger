A fix for the layout breaking after going back.

**This is still an early test release.** Save a backup (More → Backup and import)
before you update.

## Fixed

- After pressing a "back" link, for example from the claim report to its tour, the
  page was squeezed into a narrow column and the figures could not be read. This
  affected every page reached by going back.

## Updating from 0.1.0

Install over the version you have; your entries stay. On Android, this APK is signed
with the same key as 0.1.0, so there is nothing to uninstall.

## Which file

| System | File |
|---|---|
| macOS 11 or later (Apple silicon and Intel) | `…_universal.dmg` |
| Windows, most PCs | `…_x64-setup.exe` or `…_x64_en-US.msi` |
| Windows on ARM | `…_arm64-setup.exe` |
| Debian, Ubuntu | `…_amd64.deb` or `…_arm64.deb` |
| Fedora, openSUSE | `…x86_64.rpm` or `…aarch64.rpm` |
| Other Linux (64-bit PC) | `…_amd64.AppImage` |
| Android 8 or later (ARM phones and tablets) | `…_android.apk` |

iPhone and iPad are not included. FreeBSD can only be built from source.

## Security warnings you will see

The desktop apps are not signed with a paid developer certificate.

- **macOS:** open the app once, then go to System Settings → Privacy & Security and
  choose **Open Anyway**.
- **Windows, SmartScreen warning:** choose **More info → Run anyway**.
- **Windows, Smart App Control:** where it is switched on, Windows blocks the
  installer and offers no way to allow just this app.
- **Android:** allow your browser or file manager to install apps when asked.

## What has been tested

- The fix: every back step, at phone and desktop widths, in a browser against the
  same code the app runs.
- Windows, Linux and Intel Macs: built automatically, never tested by us.

Please report what breaks in the repository's Issues.
